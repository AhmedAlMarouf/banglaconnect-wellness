# BanglaConnect Wellness

A simple, static website for BanglaConnect Wellness — a volunteer-run diabetes
awareness initiative for Bangladeshi immigrant communities in Canada.

## Files

- `index.html` — all page content
- `styles.css` — design and layout
- `script.js` — mobile menu toggle

No build step, no dependencies. It's plain HTML/CSS/JS, so it works as-is on
GitHub Pages.

## Before you publish — replace these placeholders

- `hello@banglaconnectwellness.org` (appears in `index.html`) — swap in your
  real contact email, in the two `mailto:` links and the footer.
- The founder quote in the "Our start" section — edit the wording to sound
  like you, or replace with your own name if you'd like to sign it.
- "Serving Bangladeshi communities across Canada" in the footer — add a city
  or region if you want to be specific about where you're starting.

## Making local edits

Open `index.html` in any text editor and change the text between the tags.
To preview changes, just open `index.html` directly in a browser — no server
needed.
